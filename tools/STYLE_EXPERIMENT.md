# 문체 메트릭 실험 — "점프 투 파이썬처럼 담백하게"

## 왜 만들었나

최영림 교수 피드백에서 두 가지가 반복해서 지적됐다.

1. **굳이 붙이는 예고·과시** — "완성된 모습부터 보여드립니다", "결과물을 먼저 구경하는 시간입니다"
2. **있어 보이려고 멋 부린 재정의(중2병)** — "그렇게 보면 원본에서 초과로 기록된 값들은 유효한 초과가 아닙니다"

감으로 고치면 재발한다. 그래서 **측정 가능한 기준**을 먼저 만들었다.

## 기준선을 어디서 가져왔나

목표 문체는 『점프 투 파이썬』이다. wikidocs 15개 절을 브라우저로 받아
산문 74,729자 · 1,770문장에서 실측했다.

| 지표 | 점프 투 파이썬 |
|---|---|
| 문장 길이 평균 | 41.2자 (표준편차 18.4) |
| 예고성 메타 발화 | **0.00 / 1k자 (0건)** |
| 중2병 재정의 | **0.00 / 1k자 (0건)** |
| 극적 지시("바로 그"류) | 0.01 / 1k자 |

교수가 싫어한 두 가지가 목표 문체에는 **한 건도 없다**. 이것이 이 메트릭의 출발점이다.

## 측정 축

| 축 | 무엇 | 가중치 | 출처 |
|---|---|---|---|
| M1 예고성 메타 발화 | "~을 보여드립니다 / ~할 시간입니다" | 35 | 교수 지적 1순위 |
| M2 중2병 재정의 | "X는 Y이지 Z가 아닙니다", "유효한 ~가 아닙니다" | 30 | 교수 지적 2순위 |
| M3 독자 반응 대행 | "~가 궁금해집니다", "주의할 점이 있습니다" | 8 | codex·grok 블라인드 심사 |
| M4 대립·등치 수사 | "A는 곧 B", "~지만 ~못합니다" | 7 | codex·grok 블라인드 심사 |
| 극적 지시 | "바로 그", "~인 셈입니다" | 10 | 실측 변별 (0.21 vs 0.01) |
| 볼드 남용 | 마크다운 `**` 밀도 | 12 | taxonomy J-1 |
| 문장 길이 | JTP 41.2자에서 ±8자 허용 | 8 | 과도한 단문화 방지 |

정도부사는 **뺐다**. 우리 교재가 JTP보다 오히려 적어(0.28 vs 0.48) 변별력이 없었다.

## 검증

### 1) 구성 타당도 — 사람이 지적한 걸 잡는가
교수가 직접 지적한 문장만 모아 측정: **17.8 / 100**, M1·M2 감점 만점.
그가 든 예("유효한 초과가 아닙니다")를 정확히 집어냈다.

### 2) 변별 타당도 — AI본과 윤문본을 가르는가
교재에 없는 주제로 같은 내용을 두 벌 썼다.

| 원고 | 메트릭 | codex(블라인드) | grok(블라인드) |
|---|---|---|---|
| A. 일부러 AI 말투 | 0.0 | 48점 | 탈락 |
| B. 점프투파이썬 윤문 | 81.5 | 90점 | 선택 |

두 심사자에게는 어느 쪽이 윤문본인지 알리지 않았다. 둘 다 B를 골랐고,
근거로 **교수가 지적한 것과 같은 문장**을 인용했다.

### 3) 수렴 타당도 — 심사자가 본 걸 메트릭도 보는가
심사자들이 B에서 찾아낸 잔여 AI 티("궁금해집니다", "주의할 점이 있습니다",
"~지만 ~못합니다", "A는 곧 B")를 M3·M4로 넣자 B 점수가 96.5 → 81.5로
내려가 codex 평가(90점)와 방향이 맞았다.

## 게이트 (교재 수정 통과 조건)

```
python tools/style_metric.py chapters/ --gate
```

| 조건 | 값 |
|---|---|
| 종합 점수 | ≥ 85 |
| 예고성 메타 발화 | **0건 (무관용)** |
| 중2병 재정의 | **0건 (무관용)** |
| 극적 지시 | ≤ 0.05 / 1k |
| 독자 반응 대행 | ≤ 0.10 / 1k |
| 대립 수사 | ≤ 0.10 / 1k |
| 볼드 | ≤ 2.0 / 1k |
| 문장 길이 평균 | 33 ~ 50자 |

문장 길이 하한이 중요하다. 1차 윤문본이 24.4자까지 짧아져 게이트에 걸렸다.
**담백하게 고치라는 것이지 토막 내라는 게 아니다.**

## 한계 (알고 쓸 것)

- 정규식 기반이라 **패턴만 피하면 점수가 오른다.** 점수는 "알려진 나쁜 버릇이 없다"는
  뜻이지 "좋은 글"이라는 뜻이 아니다. 그래서 블라인드 심사를 병행한다.
- 메트릭 설계자와 윤문 실행자가 같으면 자기검증 편향이 생긴다. 롤아웃 때도
  표본을 뽑아 codex·grok 블라인드 심사를 다시 돌린다.
- 산문 3,000자 미만에서는 비율 지표가 불안정하다(경고 출력).
- 어체(습니다체 vs 이다체)는 측정하지 않는다. JTP는 이다체지만 우리 교재는
  습니다체이며, 교수 지적은 어체가 아니라 과시 어법에 대한 것이었다.

## 검수 피드백 루프 (놓친 표현을 탐지 범위에 넣기)

메트릭은 정규식이라 처음부터 모든 AI 티를 알 수 없다. 그래서 검수자가 발견한
표현을 곧바로 규칙에 넣을 수 있게 해 두었다.

**검수 페이지** — 윤문 전후로 바뀐 문장만 모아 놓았다. 카드마다 "AI 티 남음"
버튼이 있고, 상단에 문구를 직접 적는 칸도 있다. 표시한 내용은 아티팩트 db 에 쌓인다.

**표시한 것을 규칙으로 옮기기**

```
# 1) 아티팩트 db 의 flags 컬렉션을 읽는다 (Artifact 도구 read_db)
# 2) 추가하기 전에 교재 어디에 있는지 확인
py tools/add_pattern.py --scan "구경하는 시간입니다"

# 3) 알맞은 축에 추가 (정규식 몰라도 됨 — 문자열은 자동 이스케이프)
py tools/add_pattern.py --axis meta "구경하는 시간입니다" "소개해 드립니다"

# 4) 기존 축에 안 맞으면 새 축을 만든다
py tools/add_pattern.py --new-axis cliche --label "상투어" --weight 8 "말 그대로"

# 5) 다시 채점
py tools/style_metric.py chapters/ --gate
```

`tools/style_patterns.json` 의 `user_phrases` 에 들어간 문구는 `style_metric.py`
가 바로 읽어 쓴다. 코드는 고칠 필요가 없다.

**축 목록 보기**: `py tools/add_pattern.py --list`

## 알려진 사각지대 (실제로 겪은 것)

- **제목은 산문에서 제외돼 검사되지 않았다.** 교수가 지적한 1순위 문구
  "완성된 모습부터 보여드립니다"가 하필 절 제목이라 메트릭에 안 잡혔다.
  지금은 `heading_hits()` 로 제목도 따로 검사하고, 게이트가 무관용으로 막는다.
- **볼드로 끝나는 줄은 문장 추출에서 빠졌다.** `**...**` 로 끝나는 줄이 문장
  종결 조건을 만족하지 않아, 볼드를 풀고 나서야 안에 있던 위반이 드러났다.
  볼드 정리와 문구 수정을 함께 돌린 뒤 재측정하는 순서가 맞다.
- 산문 3,000자 미만에서는 비율 지표가 불안정하다(경고 출력).

## 2차 검증 — 다른 책, 다른 장르 (윤리 교재 1장)

『바이브코딩으로 배우는 인공지능 윤리』 1장 워드 원고로 메트릭의 이식성을 시험했다.

**드러난 문제 두 가지**

1. **오탐** — "공식 안내 링크와 마지막 확인일을 보여 줍니다"가 예고성 메타로 걸렸다.
   서비스 동작 서술인데 잡힌 것이다. `보여 줍니다`를 패턴에서 빼고 독자를 향한
   `보여 드립니다`만 남겼다.
2. **장르 과적합** — "3장에서 살펴봅니다"(상호참조), "다음 장에서는 ~ 구분해
   보겠습니다"(다음 장 예고), 학습목표 불릿의 "알아봅니다"가 지도책의 과시형
   ("구경하는 시간입니다")과 같은 무게로 감점됐다. 축을 둘로 나눴다.
   - `meta` 과시형 (보여 드립니다 / 구경하는 / ~할 시간입니다) 가중치 35, 무관용
   - `meta_soft` 관행적 (살펴봅니다 / 알아봅니다 / 해 보겠습니다) 가중치 8, 0.5/1k 허용

   65.0 → 92.0 으로 정정. 앞의 점수는 잘못된 것이었다.

**정규식이 못 보는 것 — 독립 심사로 찾았다**

codex 블라인드 심사가 78/100을 매기며 지적한 핵심은 단어가 아니라 **문단 구성**이었다.

> 특정 단어보다 '사례 → 일반화 → 단서 → 당위'로 비슷하게 닫히는 문단 구성에서 AI 느낌이 난다.

세 패턴을 `add_pattern.py` 로 축에 추가했다.

| 축 | 무엇 | 예시 문구 |
|---|---|---|
| `abstract_close` 설명 뒤 뜻풀이 | 사례로 이미 전한 의미를 추상 문장으로 다시 정리 | "함께 살펴보는 것입니다", "이런 구체적인 선택으로 이어집니다" |
| `preempt` 선제적 오해 차단 | 설명마다 "그렇다고 ~인 것은 아니다"를 덧붙임 | "단정할 수는 없습니다", "뜻은 아닙니다" |
| `nominalize` 행동을 판단 용어로 감싸기 | 바로 쓸 수 있는 동작을 추상 명사로 우회 | "판단이 가능합니다", "방안을 검토합니다" |

추가 후 윤리 원고 92.0 → **70.0** 으로 내려가 codex 평가(78)에 근접했다.
지도 교재는 98.3으로 30/30 게이트를 유지했다(신규 축 거의 0건).

**교훈** — 정규식 메트릭은 어휘를 보고 사람은 구조를 본다. 점수만 믿지 말고
장르가 바뀔 때마다 블라인드 심사를 한 번은 돌려야 한다. 심사가 짚어 준 문구는
`add_pattern.py` 로 바로 축에 넣을 수 있다.

**주의** — 이 문구들은 금칙어가 아니다. codex의 표현대로 "앞뒤 문맥을 다시 읽을
위치를 찾는 표지"다. 그래서 무관용(0)이 아니라 밀도 상한(0.3~0.5/1k)으로 뒀다.
