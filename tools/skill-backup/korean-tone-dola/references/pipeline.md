# Dola에 맡겨 윤문하는 방법

원고가 한 장 넘게 길면 직접 고치지 말고 Dola에 맡긴다. 다만 Dola는 말투는
잘 다듬는 대신 **내용을 망가뜨린다.** 아래 안전장치 없이 결과를 그대로 쓰면 안 된다.

교재 29장을 돌리며 실제로 겪은 것들이다.

## Dola가 망가뜨리는 것

| 증상 | 실제 사례 |
|---|---|
| 인용부호 안 예시 프롬프트를 바꿔 씀 | "차분하게 바꿔줘" → "강하도록 변경해줘" (뜻이 뒤집힘) |
| 백틱을 지움 | `node -v` → node -v |
| 문장을 통째로 지움 | "코딩을 배우지 않아도 된다는 뜻이 아닙니다"가 사라짐 |
| 문단 번호를 밀어 씀 | 그림 캡션 자리에 옆 문단의 답이 들어옴 |
| 뜻을 바꿈 | localStorage → "위치 정보" |
| 없던 설명을 늘림 | 한 문단이 2,800%까지 늘어남 |

## 보내기 전

1. **산문 문단만 보낸다.** 제목(`#`), 그림(`![...]`), 캡션(`///`), 팁 상자(`!!!`),
   코드 블록(```` ``` ````), 표(`|`), 인용(`>`), 각주 정의(`[^1]:`), 목록(`- `, `1. `)은
   보내지 않는다. 보내면 반드시 망가진다.
2. **문단마다 번호를 붙인다.** `[1] 문단`, `[2] 문단` … 돌아온 답을 번호로 되꽂는다.
3. **바뀌면 안 되는 조각을 토큰으로 가린다.** 인라인 코드, 큰따옴표 안 문구, 각주
   표시를 `【1】` `【2】`로 바꾸고 표를 따로 저장한다.
4. **파일로 첨부한다.** 긴 글을 붙여넣기로 넣으면 클립보드가 다른 작업과 부딪힌다.
   `.txt`로 첨부하면 안정적이다.

보내는 글머리에 붙이는 규칙:

```
아래는 한국어 프로그래밍 교재의 본문 문단입니다. 말투를 자연스럽게 다듬어 주세요.

규칙
1. 번호를 그대로 유지하고, 문단 하나당 한 덩어리로 답해 주세요. 문단을 합치거나 나누지 마세요.
2. 【1】 【2】 처럼 꺾쇠 안에 숫자가 든 표시는 건드리지 마세요. 숫자를 바꾸지도, 지우지도 말고
   문장 안에서 원래 있던 자리에 그대로 두세요. 명령어와 예시 문구를 가려 둔 자리입니다.
3. 숫자와 영문 용어는 그대로 두세요.
4. 문장을 지우지 마세요. 문단의 정보량이 줄지 않게 해 주세요.
5. 합니다체로 씁니다. 이모지는 넣지 마세요.
6. 설명이나 요약은 붙이지 말고 번호와 다듬은 문단만 주세요.
```

## 돌아온 뒤 — 다섯 가지 가드

문단 하나라도 아래에 걸리면 **그 문단은 원문을 쓴다.** 말투를 얻자고 내용을
잃지 않는다.

| 가드 | 기준 | 잡는 것 |
|---|---|---|
| 토큰 유실 | 보낼 때 있던 `【n】`이 답에 없음 | 명령어·예시 문구가 사라진 문단 |
| 분량 축소 | 원문의 80% 미만 | 문장을 지운 문단 |
| 분량 폭증 | 원문의 260% 초과 | 없던 설명을 지어낸 문단 |
| 번호 밀림 | 제자리 문단보다 이웃 문단과 낱말이 더 겹침 | 답이 한 칸씩 밀린 구간 |
| 백틱 깨짐 | 백틱 개수가 원문과 다름 | 인라인 코드 표시가 깨진 문단 |

번호 밀림은 낱말 겹침이 낮은 것만으로 판단하면 안 된다. Dola는 낱말을 통째로
바꿔 쓰기 때문에 정상 윤문도 겹침이 0.1까지 내려간다. **제자리보다 이웃이 훨씬
더 닮았을 때만** 밀린 것으로 본다.

## 마지막 확인

되꽂은 뒤 원문과 대조해 아래가 그대로인지 센다.

- 큰따옴표 안 문구
- 인라인 코드
- 숫자
- 각주 표시
- 코드 블록, 헤딩, 그림, 표의 개수

하나라도 어긋나면 그 문단을 되돌린다.

## 자동화

이 리포(`H:\YLBooks2`)에 도구가 들어 있다.

```bash
py tools/dola_prep.py extract chapters/ch01.md --out 윤문비교/ch01/보낼산문.txt
py tools/dola_run.py ch01              # Dola 데스크톱에 CDP로 붙어 자동 실행
py tools/dola_merge.py ch01            # 되꽂기 + 가드 + 무결성 검사
```

`dola_run.py`는 Dola 데스크톱(Cici)을 `--remote-debugging-port=9333`으로 띄운 뒤
Playwright로 붙어 장마다 새 대화를 열고 파일을 첨부해 보낸다. 한 장에 100초쯤
걸린다. **대화를 새로 열 때 화면을 다시 띄우지 않으면 앞 장의 첨부 파일이 쌓여**
여러 장을 섞어 읽는다. 첨부가 한 개인지 세고 나서 보낸다.
