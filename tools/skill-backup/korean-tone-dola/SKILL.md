# 한국어 문체: Dola 기준

저자(조성호)는 내 문체를 여러 번 물렸고, Dola가 다듬은 글을 택했다.
그 판단은 이미 끝났으니 다시 논쟁하지 않는다. **Dola 쪽이 기준이다.**

근거: 교재 29장, 짝 지은 문단 1,439개(원문 21.8만 자 → Dola 28.1만 자)를
전수 비교해 뽑은 수치다. 자세한 표는 `references/evidence.md`.

## 먼저 지킬 것

1. **내 문체 감각으로 반론하지 않는다.** "이건 더 딱딱해졌다" 같은 품질 논평을
   덧붙이지 않는다. 저자가 이미 판단했다.
2. **고칠 때 내용을 건드리지 않는다.** 말투만 바꾼다. 인용부호 안의 문구,
   명령어, 숫자, 파일 이름, 각주는 한 글자도 손대지 않는다.
3. 다 고친 뒤 `scripts/check_tone.py`로 훑는다.

## 쓰지 말 것

저자가 직접 지적했거나, Dola가 일관되게 걷어낸 것들이다.
괄호 안은 1,000자당 사용 빈도 변화(원문 → Dola).

| 쓰지 말 것 | 대신 | 근거 |
|---|---|---|
| `~할 겁니다` | `~할 것입니다` | 244회 → 22회 (−1.04) |
| `~해 봅시다` | `~해 보겠습니다` | 152회 → 17회 (−0.64) |
| `~해 보세요`, `~확인하세요` | `~해 보시기 바랍니다`, `~하십시오` | 252회 → 50회 (−0.98) |
| `~하는 것은 아닙니다` (불필요한 부정대조) | 긍정문으로 바로 | 96회 → 53회 |
| `A가 아니라 B` | `B입니다` | 30회 → 7회 |
| `~남습니다` | `~유지됩니다`, `~그대로입니다` | 14회 → 0회 |
| `눈으로 확인`, `손으로 만든` | `확인`, `직접 만든` | 26회 → 3회 |
| `쓰다/씁니다` | `사용합니다`, `활용합니다` | 324회 → 40회 |

### 저자가 문장을 그대로 인용하며 지적한 것

- **예고성 메타 발화.** "완성된 모습부터 보여 드립니다", "결과물을 먼저
  구경하는 시간입니다" — 굳이 예고하지 말고 바로 본론으로 들어간다.
- **있어 보이려는 재정의.** "그렇게 보면 원본에서 초과로 기록된 값들은 유효한
  초과가 아닙니다" — 뜻이 더해지지 않는데 개념을 다시 정의하는 문장.
  저자 표현으로 "중2병처럼 말하는 것".
- **부정대조 습관.** "우리가 컴퓨터로 그렸다고 하면 되지 뭘 그렇게 아니고 했다
  투를 쓰냐" — `A가 아니고 B다` 대신 `B다`로 바로 쓴다.
- **말장난 제목.** "입구는 둘, 문은 하나", "자랑하기 3단계 코스" 같은 비유는
  Dola가 전부 평서형으로 바꿨다.

또한 감탄("드디어", "!"), 독자를 아는 척하는 문장("~하실 겁니다", "궁금하시죠"),
억지 유보("~으로 보입니다", "~일 수도 있습니다"를 근거 없이 붙이기)를 쓰지 않는다.

## 이렇게 쓸 것

| 쓸 것 | 근거 |
|---|---|
| `~것입니다`로 단정 | 37회 → 382회 (+1.19) |
| `~시기 바랍니다`로 권유 | 0회 → 221회 (+0.79) |
| `~해 보겠습니다`로 안내 | 72회 → 240회 (+0.52) |
| 지시어를 `해당 ~`으로 | 4회 → 274회 (+0.96) |
| `~때문입니다`로 근거를 뒤에 | 62회 → 131회 (+0.18) |
| `반면`, `예를 들어`, `즉`, `따라서` | 각각 4~5배 |
| 동사는 한자어로: 사용·활용·표시·제시·요청·삭제·병합 | 1회 → 332회 |

### 문장 길이

원문 37자 → Dola 48자. **짧게 끊지 말고 이어 붙인다.** 문단당 문장 수는
3.9개로 같으니, 문단을 쪼개라는 뜻이 아니라 한 문장을 충분히 길게 쓴다는 뜻이다.

```
쓰지 말 것: 열다섯 줄 남짓이라 짧아 보입니다. 그렇다고 새로 배울 것까지
            적은 것은 아닙니다. 위에서부터 함께 읽어 봅시다.
쓸 것:      코드의 길이는 약 15줄 정도로 간결하지만, 그렇다고 새롭게 배울
            내용이 적은 것은 아닙니다. 코드의 첫 부분부터 함께 자세히
            살펴보겠습니다.
```

### 생략된 말을 되살린다

주어와 목적어를 줄이지 않는다. "설치는 10분이면 넉넉할 겁니다" 대신
"설치에는 대략 10분 정도면 충분합니다".

## 고칠 때의 순서

원고가 길면 직접 고치지 말고 Dola에게 보낸다. 사람 손이 덜 가고 결과가 낫다.
방법과 안전장치는 `references/pipeline.md`에 있다. 요점만:

1. 산문 문단만 뽑아 보낸다. 제목·그림·코드 블록·표는 보내지 않는다.
2. 인용부호 문구, 인라인 코드, 각주는 `【1】` 같은 토큰으로 가려서 보낸다.
3. 돌아온 문단이 **토큰을 잃었거나, 분량이 80% 아래로 줄었거나, 260% 넘게
   늘었거나, 이웃 문단과 더 닮았거나, 백틱 개수가 달라졌으면** 그 문단은
   원문을 쓴다. Dola는 번호를 밀어 쓰거나 문장을 지우는 일이 있다.

## 검사

```bash
py ~/.claude/skills/korean-tone-dola/scripts/check_tone.py 원고.md
py ~/.claude/skills/korean-tone-dola/scripts/check_tone.py chapters/*.md --quiet
```

줄 번호와 함께 걸린 표현을 보여 준다. **금지 항목은 0건이 목표다.**
`--all`을 붙이면 주의 항목까지 본다.

검사기가 제대로 가르는지 같은 원고로 확인했다.

| | 금지 항목 |
|---|---:|
| 윤문 전, 내가 쓴 29장 | 575곳 |
| 윤문 후, Dola가 다듬은 29장 | 76곳 |

87%가 걷힌다. 남은 76곳은 가드에 걸려 원문을 그대로 둔 문단들이다.
