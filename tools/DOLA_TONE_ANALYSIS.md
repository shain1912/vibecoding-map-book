# Dola 말투 분석 — 0장 대조로 뽑은 변환 규칙

저자가 Dola(dola.com)의 한국어 말투를 "완전 자연스럽다"고 평가했다. 같은 원고(0장)를
Dola에게 주고 "AI말투 다듬어줘"라고 시킨 결과가 있어, 원문과 나란히 놓고 무엇을 바꿨는지
뽑았다. 이 문서의 모든 주장은 아래 두 파일에서 인용한 문장이 근거다.

## 0. 자료와 측정 조건

| 항목 | 내용 |
|---|---|
| 원문 | `before.txt` = `chapters/ch00.md` (diff 차이 0바이트) |
| Dola 출력 [A] | 제약 없이 "AI말투 다듬어줘"만 시킨 결과. **저자가 자연스럽다고 평가한 버전** |
| Dola 출력 [B] | 합니다체·이모지 금지·부정대조 금지·내용 불변을 지시한 결과 (원문은 1장 도입부) |
| 대조 범위 | [A]는 0.1절 팁 상자까지만 다시 썼다. 정량 비교는 그 구간으로 맞췄다 |

측정은 `tools/tone_scan.py`(교수님 원고 톤 게이트)를 두 구간에 똑같이 돌려 얻었다.

## 1. 정량 대조 — 숫자가 먼저 말하는 것

`py tools/tone_scan.py` 실측 (1000자당, 산문 기준):

|---|---|---|---|---|
| 위반 총건수 | **0건** | **7건** | — | — |
| 구어체 죠 | 0.00 | 3.08 | == 0 | **FAIL** |
| 60자 초과 문장 % | 5.13 | 25.71 | <= 8 | **FAIL** |
| 문장 길이 평균 | 32.41자 | 46.40자 | 29~43 | **FAIL** |
| 유보형 종결 % | 28.21 | 20.00 | >= 20 | ok |
| `~입니다` 종결 비중 % | 5.13 | 11.43 | <= 13.3 | ok |
| em대시 / 볼드 / 문장형 괄호 | 0 / 0 / 0 | 0 / 0 / 0 | == 0 | ok |

| 복수 접미사 `들` | 0 | **4** |

**가장 중요한 수치 사실: 글자는 28% 늘었는데 문장 수는 줄었다.** Dola의 "자연스러움"은
문장을 짧게 끊어서 나온 것이 아니다. 반대로 **문장을 합치고 살을 붙여서** 나왔다.
원문이 게이트를 0 위반으로 통과하는데도 저자가 Dola를 더 낫다고 했다는 사실은,
저자가 느끼는 자연스러움이 우리 게이트가 재는 층과 다른 층에 있다는 뜻이다.

## 3. 변환 규칙 추출

반복 횟수와 근거 짝 번호를 붙였다. 괄호 안은 §2 표의 # 번호다.

### 종결 처리

- **R1. 평서 추측을 해요체 수사 의문으로 바꾼다.** 「~있을 겁니다」·「~가겠지요」 →
  「~겠죠?」 (10, 11). 구간 8회, 물음표 0→4개.
- **R2. 청유 「~봅시다」를 「~볼까요?」로 바꾼다.** (12) 독자에게 동의를 구하는 형태로 돌린다.
- **R3. 단정 종결에 「~죠」를 붙여 낮춘다.** 「나타납니다」→「나타나죠」 (13).
- **R4. 유보형을 평가 형용사로 교체한다.** 「정리하면 되겠지요」→「정리하면 깔끔하겠죠」 (14),
  「간단한 것은 아닙니다」→「알차게 준비되어 있습니다」 (22). **부정 종결을 긍정 평가로 뒤집는다.**
- **R5. 동사 종결을 명사 서술로 바꾼다.** 「우리가 그렸습니다」→「우리가 만든 디자인입니다」 (15).

### 문장 길이

- **R6. 인접 두 문장을 연결어미로 합친다.** -고 / -어 / -지만 (21, 22, 23, 24).
  연결어미 6→14개, 문장 39→35개, 글자 +28%. **평균 32.4자 → 46.4자.**
- **R7. 단 요지 문장 한 개는 줄 단위로 떼어 세운다.** 「화면은 크게 두 부분으로 나뉩니다.」를
  독립 줄로 올린 뒤 줄바꿈하고 본문을 붙였다 (26). 길게 합치되 **단락 머리에 짧은 한 줄**을 둔다.
- **R8. 문장 중간을 물음표로 끊어 질문을 심는다.** 「검색으로 찾기 어려운 장소라면?」 (33).

### 접속·연결

- **R9. 예시 앞에 「예를 들어」를 붙인다.** (13, 17, 33) 원문에는 없던 접속이다.
- **R10. 쉼표 열거에 「과/그리고」를 끼운다.** 「검색창, 카테고리 필터 버튼, 목록」 →
  「검색창과 카테고리 필터 버튼, 그리고 … 목록」 (21).
- **R11. 헤딩·절 첫머리 뒤에 쉼표를 넣어 호흡을 만든다.** 「핀을 누르면, 장소 정보가」 (4, 5, 6).

### 독자 호칭

- **R12. 「여러분」을 지우고 1인칭(내가/우리)으로 돌린다.** (27, 28) 「여러분」 1→0회.
  2인칭 명령 「생각해 보세요」를 정의문으로 바꿨다 (27).
- **R13. 명령문을 가능 서술로 완화한다.** 「눌러 보세요」→「누르면 ~할 수 있습니다」,
  「추가하면 됩니다」→「추가하는 것도 가능합니다」 (33).
- **R14. 「-시-」와 「드리다」로 공대를 덧붙인다.** 「넘어가셔도」, 「설명해 드릴 테니」 (34, 41).
  단 [B]에서는 반대로 「닫으셨을지도」의 「-시-」를 **지웠다** (44). 일관성이 없다.

### 강조·수식

- **R15. 강화 부사를 심는다.** 정말·전혀·꼭·그냥·가볍게·바로·간단히·자유롭게·쏙 → 0→10회
  (10, 34, 42, 43). 의태어 「쏙」까지 넣는다.
- **R16. 평가 형용사를 없던 자리에 붙인다.** 맛있는 국밥집, 특별한 장소, 더 편리한 기능,
  알차게 준비된 (16, 17, 22, 35).
- **R17. 복수 접미사 「들」을 붙인다.** 이런 곳들, 기능들, 위 기능들 → 0→4회 (25, 34, 35).

### 구조 추가

- **R18. 장 첫머리에 요약 리드문을 신설한다.** 원문에 없던 문장을 만들어 넣는다 (2).
- **R19. 헤딩과 불릿 앞에 이모지를 붙인다.** `###` 기호를 떼고 📍🔘🔍⭐💡✅로 대체
  (3~8). 이모지 9→19개, 그중 10개가 순수 장식이다.
- **R20. 마크다운 구조 문법을 평문으로 녹인다.** admonition(`!!! note`), 이미지 참조,
  `/// caption`, `{ width }`를 전부 없앴다 (3, 8, 9). **조판 정보가 소실된다.**
- **R21. 독자의 내심을 대사로 만들어 넣는다.** 「"아, 이런 것들을 만드는 거구나" 하고」 (34).

### 어휘 교체 경향

- **R22. 고유어를 한자어·외래어로 올린다.** 그→해당, 눌러→클릭, 자료→데이터, 쓰다→작성하다,
  배정→할당, 옮겨 가다→이동하다 (29, 30, 31, 41, 47).
- **R23. 번역투 「~에 대해」·「~를 바탕으로」를 도입한다.** (31, 41)

### 4.2 내용 보존 위반 — 문체 문제가 아니라 사고

`tools/content_integrity.py`가 막는 범주다. TONE_SPEC 「절대 건드리지 않는 것: 코드 블록,
명령어, **수치**, 파일·함수 이름, 이미지 참조, `/// caption`, 인라인 코드, 각주 번호」.

- 수치 삭제: 「100개」→「많아지면」 (36)
- 예시 데이터 변조: 메모 문구, 「여기서 보자」→「여기서 만나자」 (37, 38)
- **프롬프트 문구 변조: 「띄워줘」→「보여줘」** (51) — 독자가 그대로 따라 칠 문장이다
- 인용 파손: 카파시 직접 인용의 따옴표 제거 (52), 프롬프트 따옴표 전부 제거 (51)
- 용어 파손: 「커스텀 오버레이」→「맞춤형 오버레이」 (39) — 이후 장의 용어와 어긋난다
- 조판 파손: 이미지 참조·`/// caption`·`{ width }`·admonition 소실 (9, 20)
- 분량 +28% (원문에 없던 리드문·평가어·접속 추가)

**[B]처럼 제약을 걸어도 (51)(52)는 막히지 않았다.** 따옴표와 인용 원문 보존은 별도로
명시해야 한다.

### 4.3 우리 검사기의 구멍 — 이번 대조에서 드러난 것

Dola 출력을 `tone_scan.py`에 통과시켜 보니, **해요체의 대부분이 잡히지 않았다.**

| 구멍 | 사실 | 위치 |
|---|---|---|
| G1 | 「~이에요」·「~거예요」·「~볼까요?」가 **검출 0건**. 「구어체 훅」 정규식에 `죠/거죠/것이죠/니까요/답니다/군요/네요`만 있고 **`이에요·예요·거예요·~까요?`가 없다** | `tools/tone_scan.py` 「구어체 훅」 패턴 |
| G2 | 이모지 19개 중 **💡 1개만 검출**. 장식 이모지 패턴이 고정 문자 집합(🗣💡⚠🔎📌🤔✏✍🍎)이라 ✅⭐📍🔘🔍😊가 전부 빠져나간다 | `tools/tone_scan.py:112` |

원문 0장이 **위반 0건·게이트 전체 통과**인데도 저자가 Dola를 더 자연스럽다고 평가한 사실과
합치면 결론은 하나다. **게이트 통과는 문체 품질의 증명이 아니다.** 메모리에 적힌
「빈도 검사기로는 못 잡는다. 읽어야 보인다」가 이 대조로 다시 확인됐다.

### 4.4 그래서 Dola의 무엇이 "자연스러움"이었나 — 채택/거부 분류

저자가 좋다고 한 [A]에서 **해요체·이모지·내용 훼손을 빼고 남는 것**이 실제 효과의 정체다.
아래는 우리 기준과 충돌하지 않는다.

채택 가능 (기준 위반 없음)

- **R6 문장 합치기** — 단, 게이트(평균 29~43자, 60자 초과 ≤8%) 안에서. 현재 0장 평균이
  31.3자로 하한에 붙어 있다. **43자 쪽으로 올릴 여유가 있다.** HUMANIZE_RULES도
  「문장을 잘게 토막 내지 말 것」이라고 적어 두었다. 지금 교재는 오히려 너무 토막나 있다.
- **R7 단락 머리에 짧은 요지 한 줄** — 「화면은 크게 두 부분으로 나뉩니다.」
- **R9/R10 접속 보강** — 「예를 들어」, 열거에 「과/그리고」. 0장에는 접속이 거의 없다.
- **R12 「여러분」 줄이기** — 우리 기준이 금지하지 않는데 Dola는 지웠고 저자는 그쪽을 좋아했다.
  0장에 「여러분」이 4회 있다. 1인칭(내가/우리)으로 돌리면 호칭이 한결 차분해진다.
- **R13 명령문 완화** — 0장은 「보세요」가 9회다. 일부를 「~할 수 있습니다」로 바꿀 자리가 있다.
- **R22의 일부** — 「쳐 보면」→「입력하면」처럼 **기계 조작 동사는 정확한 쪽**이 낫다.
- **[B]에서 실제로 개선된 4개** — 「닫으셨을지도 모릅니다」→「닫았을 수도 있습니다」(-시- 제거),
  「많아 보이니」→「많으니」, 「다 배우고 나서」→「모두 배운 뒤에」, 「하면 됩니다」→「요청하면 됩니다」.
  이 네 개는 V5 §4·§7과 방향이 같다. **0장에도 같은 자리가 있다**: 「쓰고 계신다면」,
  「가지고 계실 겁니다」, 「외우지 않으셔도 됩니다」, 「따라오시기를 권합니다」,
  「드셨을지도 모릅니다」 — 공대 「-시-」가 5회 섞여 어체가 일정하지 않다.

거부 (C1~C10에 걸림)

- R1~R5(해요체 종결), R8(물음표 삽입), R14(드리다), R15~R17(강화 부사·평가어·복수 들),
  R18~R21(리드문 신설·이모지 헤딩·마크다운 해체·대사 날조), R23(~에 대해).

## 6. 한 문장 결론

Dola의 "자연스러움"은 **문장을 합쳐 길게 만들고(32→46자), 접속을 보강하고, 「여러분」을
지우고, 명령을 가능형으로 낮춘 것**에서 나왔다. 여기에 **해요체·장식 이모지·강화 부사**가
얹혀 있는데 이 세 개는 우리 기준과 정면으로 충돌하고, 더 나아가 Dola는 **수치·인용·
프롬프트 문구·용어·조판을 훼손**했다. 앞의 네 가지만 가져오고 나머지는 버린다.
