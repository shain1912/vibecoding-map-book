# 바이브코딩으로 만드는 나만의 지도 웹

> AI에게 말로 시켜서, 카카오지도 기반 **나만의 맛집·여행·데이트 지도**를 만들어 세상에 공개하기까지.

이 책은 코드를 한 줄도 외우지 않고도 실제로 돌아가는 웹 서비스를 만드는 **바이브코딩(vibe coding)** 튜토리얼입니다. 여러분은 AI 코딩 에이전트(Claude Code)에게 일을 시키고, 결과를 확인하고, 마음에 안 들면 되돌립니다. 그렇게 26개 장을 지나면 아래 것들이 손에 남습니다.

- 📍 **나만의 지도 웹앱** — 마커, 말풍선, 카테고리 필터, 장소 검색, 저장, 공유까지 되는
- 🌐 **인터넷에 공개된 내 서비스** — GitHub Pages 주소를 친구에게 보낼 수 있는
- 🛠 **바이브코딩 작업 환경** — Node.js, Git, Claude Code, GitHub CLI, Orca
- 💪 **AI에게 일 시키는 감각** — 어떤 프로젝트에든 다시 써먹을 수 있는

## 이 책의 구성

| 부 | 장 | 내용 |
|---|---|---|
| 1부 바이브코딩 준비운동 | 1–6장 | 도구 설치와 AI에게 일 시키는 법 |
| 2부 카카오 지도 첫걸음 | 7–10장 | API 키 발급부터 지도 띄우기까지 |
| 3부 나만의 장소 지도 만들기 | 11–19장 | 마커·필터·검색·저장·상세 패널 |
| 4부 한 단계 더 | 20–23장 | 내 위치·공유·클러스터·모바일 |
| 5부 세상에 공개하기 | 24–26장 | GitHub·배포·README |

준비물은 세 가지입니다: **윈도우 PC**, **카카오 계정**, 그리고 **Claude Pro 구독**(무료 대안 에이전트는 4장에서 소개합니다). 여기에 **호기심**만 챙기면 준비 끝입니다. 0장부터 시작해 봅시다.
