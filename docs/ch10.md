# 10장 지도 다루기

!!! note "이 장에서 배우는 것"
    - 지도 객체의 메서드를 호출해 지도를 조작하는 방법을 배웁니다: 콘솔에서 직접 지도를 움직여 봅니다
    - `setCenter`와 `panTo`의 차이(즉시 이동과 애니메이션 이동)를 이해합니다
    - `setLevel`로 확대·축소하며 레벨 숫자와 축척 감각을 익힙니다
    - 지도에 MapTypeControl(지도 타입 버튼)과 ZoomControl(확대·축소 버튼)을 답니다
    - `click`, `dragend` 이벤트로 지도의 신호를 받아, 클릭한 곳의 좌표를 콘솔에 찍어 봅니다

---

9장에서 브라우저 화면 가득 카카오지도를 띄웠습니다. 그런데 지금 지도는 보기만 할 수 있습니다. 마우스로 끌면 움직이고 휠을 돌리면 확대되지만, 그것은 카카오 SDK가 기본으로 제공하는 동작이고 우리 코드가 지도에 무언가를 지시한 적은 아직 없습니다.

이번 장에서는 코드로 지도를 조작하는 방법을 배웁니다. 지도를 특정 위치로 옮기거나 확대 단계를 바꾸거나 버튼을 추가하고, 반대로 지도가 보내오는 신호를 받습니다. 사용자가 어디를 클릭했는지, 지도를 끌어서 이동했는지가 그 신호에 담깁니다. 지시를 내리는 쪽을 메서드라고 하고, 신호를 받는 쪽을 이벤트라고 합니다. 이번 장에서 이 두 가지를 다루며, 앞으로 만들 기능 대부분은 이 둘을 조합해 만듭니다. 11장의 마커도, 16장의 지도 클릭으로 장소 추가도 여기서 배우는 메서드와 이벤트를 씁니다.

이번 장에도 코드는 Claude Code에게 시키고 나온 코드를 함께 읽습니다. 다만 이번에는 브라우저 개발자도구 콘솔에서 지도를 직접 조작해 보는 실습이 하나 더해집니다. 코드를 고치고 저장하지 않고도 명령을 한 줄 입력하면 지도가 바로 반응합니다.

## 10.1 지도 조작하기: Map 객체와 메서드

9장에서 지도를 만들 때 이런 코드를 봤습니다.

```js
const map = new kakao.maps.Map(container, {
  center: new kakao.maps.LatLng(37.5665, 126.978),
  level: 7,
});
```

여기서 `map`이라는 변수를 보세요. `new kakao.maps.Map(...)`이 만들어 준 지도 객체가 이 변수에 담겨 있습니다. 이 객체는 화면에 보이는 지도이면서, 동시에 그 지도를 조작하는 통로 역할을 합니다. 지도 객체에는 `setCenter`(중심 이동), `setLevel`(확대 레벨 변경), `getCenter`(현재 중심 반환) 같은 기능이 들어 있습니다. 객체에 딸린 이런 기능을 메서드[^1]라고 부릅니다. `map.setLevel(3)`처럼 객체 이름, 점, 메서드 이름, 괄호 순서로 씁니다.

그런데 이 지도 객체는 지금 코드 안에만 있어서 직접 실행해 볼 수가 없습니다. 코드를 고치고 저장해야만 결과를 볼 수 있으면 여러 값을 시험해 보기 번거롭습니다. 그래서 지도 객체를 브라우저 콘솔에서도 쓸 수 있게 해 두겠습니다. Claude Code에게 이렇게 시키세요.

!!! tip "이렇게 물어보세요"
    > main.js에서 만든 지도 객체를 브라우저 개발자도구 콘솔에서도 만질 수 있게 window에 노출해줘. 실험용이라는 주석도 달아줘.

Claude Code가 `main.js`의 지도 생성 코드 아래에 한 줄을 추가해 줍니다.

```js
window.__map = map; // 콘솔 실험용 — 브라우저 콘솔에서 __map으로 접근
```

`window`는 브라우저의 전역 공간입니다. 여기에 붙여 둔 것은 개발자도구 콘솔에서 이름만 부르면 바로 잡을 수 있습니다. 이름 앞에 밑줄 두 개를 붙이면 "이건 정식 기능이 아니라 개발용 뒷문"이라는 뜻으로 통합니다. 개발자들이 오래 써 온 관례입니다.

이제 개발 서버(`npm run dev`)가 켜진 상태에서 브라우저로 가서, F12 키를 눌러 개발자도구를 열고 Console 탭을 클릭하세요. 그리고 입력란에 이렇게 쳐 봅니다.

```js
__map.setLevel(3)
```

엔터를 누르면 지도가 골목이 보일 정도로 확대됩니다. 코드 파일은 고치지 않았는데 지도가 움직였습니다. 콘솔은 지금 열려 있는 페이지의 자바스크립트를 직접 실행할 수 있는 곳이라서, 명령을 그때그때 시험해 보기에 적합합니다.

![콘솔에서 __map.setLevel(3)을 실행해 확대된 지도](images/ch10/ch10-f01.jpg){ width="820" }
/// caption
그림 10.1 — 콘솔에서 __map.setLevel(3)을 실행해 확대된 지도
///

이번엔 지도에게 물어보겠습니다. 콘솔에 다음 한 줄을 쳐 보세요.

```js
__map.getCenter().toString()
```

`(37.5665..., 126.978...)` 비슷한 좌표가 출력됩니다. `set`으로 시작하는 메서드는 값을 바꾸는 버튼, `get`으로 시작하는 메서드는 값을 알려주는 버튼입니다. 이 짝꿍 규칙은 카카오 SDK 전체에서 통하므로, `setLevel`이 있으면 `getLevel`도 있겠구나 하고 짐작할 수 있습니다. `__map.getLevel()`을 쳐 보면 방금 바꾼 `3`이 나옵니다.

!!! tip "팁"
    콘솔에서 `__map.`까지 입력하고 잠깐 기다리면, 이 객체가 가진 메서드 목록이 자동완성으로 표시됩니다. 방향키로 훑어보되 외울 필요는 없습니다. 어떤 메서드가 있는지 한 번 확인해 두면, 나중에 Claude Code가 작성한 코드에서 낯선 메서드를 만나도 지도 객체의 기능 중 하나임을 알아볼 수 있습니다.

## 10.2 중심 이동: setCenter와 panTo

먼저 지도의 중심을 옮겨 봅시다. 중심을 옮기는 메서드는 두 개인데, 최종 결과는 같지만 이동하는 방식이 다릅니다.

콘솔에서 직접 비교해 봅시다. 지도를 서울에 둔 상태에서 즉시 이동부터 시켜 봅니다.

```js
__map.setCenter(new kakao.maps.LatLng(35.1587, 129.1604))
```

엔터를 누르면 지도가 한 번에 부산 해운대로 바뀝니다. 이동하는 중간 화면 없이 곧바로 바뀝니다. 이번에는 지도를 다시 서울로 되돌립니다. 방금 쓴 `setCenter`에 `37.5665, 126.978`을 넣으면 됩니다. 그다음 가까운 곳으로 이동해 봅니다.

```js
__map.panTo(new kakao.maps.LatLng(37.4979, 127.0276))
```

이번에는 지도가 강남역 쪽으로 이동하는 과정이 화면에 보입니다. 손으로 지도를 끌었을 때와 비슷한 애니메이션이 들어갑니다. `panTo`는 이렇게 중심을 옮깁니다. pan은 카메라를 옆으로 천천히 돌리는 촬영 기법을 뜻하는 영어 단어에서 왔습니다.

![setCenter는 즉시 이동, panTo는 애니메이션 이동](images/ch10/ch10-f02.png){ width="760" }
/// caption
그림 10.2 — setCenter는 즉시 이동, panTo는 애니메이션 이동
///

둘 중 무엇을 쓸지는 사용자가 이동 과정을 볼 필요가 있는지로 정합니다.

- setCenter: 페이지를 처음 열 때 시작 위치를 잡는 경우처럼, 이동 과정을 보여줄 필요가 없을 때 씁니다. 애니메이션이 없어 즉시 반영됩니다.
- panTo: 사용자가 목록에서 장소를 클릭해 지도가 그곳으로 이동할 때 씁니다. 화면이 한 번에 바뀌면 사용자는 지도가 어디에서 어디로 옮겨 갔는지 알기 어렵지만, 이동 과정이 보이면 위치 관계를 파악할 수 있습니다.

완성된 앱의 코드에도 이 구분이 들어 있습니다. 사이드바에서 장소를 클릭하면 실행되는 함수가 `map.panTo(pos)`를 씁니다. 18장에서 이 코드를 다시 다룹니다.

!!! warning "주의"
    `panTo`에는 규칙이 하나 있습니다. 이동할 거리가 현재 화면 크기보다 훨씬 멀면(예를 들어 서울에서 부산까지) 애니메이션을 생략하고 곧바로 이동합니다. 먼 거리를 애니메이션으로 이동하면 시간이 오래 걸리기 때문에 SDK가 이렇게 처리합니다. `panTo`를 썼는데 애니메이션이 나오지 않으면 이동 거리를 먼저 확인하세요.

그리고 좌표 이야기를 잠깐 덧붙이겠습니다. 위 실습에서 쓴 `35.1587, 129.1604` 같은 숫자는 9장에서 배운 위도·경도입니다. "그런데 해운대 좌표를 내가 어떻게 알아?"라는 의문이 당연히 들 텐데, 그렇게 생각하는 것이 맞습니다. 좌표는 외우지 않고 그때그때 얻어서 쓰는데, 이 장의 10.5절에서 클릭만 하면 좌표가 튀어나오는 장치를 만들고 12장에서는 카카오맵에서 좌표를 얻는 다른 방법도 배웁니다. 지금은 책에 적힌 좌표를 복사해 쓰면 충분합니다.

## 10.3 확대와 축소: setLevel과 축척 감각

10.1절에서 이미 `setLevel(3)`을 눌러 봤습니다. 이번에는 이 레벨이라는 숫자의 감각을 제대로 잡아 봅시다.

카카오지도의 레벨은 1부터 14까지이고, 숫자가 작을수록 크게 확대됩니다. 처음엔 방향이 헷갈리기 쉬운데, "레벨은 높이"라고 기억하면 편합니다. 레벨 1은 드론이 건물 바로 위에 떠 있는 높이, 레벨 14는 인공위성에서 한반도를 내려다보는 높이입니다. 숫자가 커질수록 높이 올라가니까 넓게 보이고, 대신 자세한 것은 안 보입니다.

콘솔에서 사다리를 오르내려 봅시다. 하나씩 쳐 보면서 지도가 어떻게 변하는지 관찰하세요.

```js
__map.setLevel(1)   // 건물 출입구까지 보이는 최대 확대
__map.setLevel(3)   // 동네 골목 수준
__map.setLevel(7)   // 도시 전체가 한눈에 (우리 앱의 시작 레벨)
__map.setLevel(11)  // 몇 개 도(道)가 함께 보이는 수준
__map.setLevel(14)  // 한반도 전체
```

레벨이 1 커질 때마다 지도에 보이는 범위는 대략 두 배로 넓어집니다. 그래서 레벨 7과 레벨 8은 별 차이가 없어 보여도, 레벨 3과 레벨 10은 보이는 것이 완전히 달라집니다.

![같은 위치, 다른 레벨: 레벨 3(왼쪽)과 레벨 7(오른쪽)](images/ch10/ch10-f03.jpg){ width="760" }
/// caption
그림 10.3 — 같은 위치, 다른 레벨: 레벨 3(왼쪽)과 레벨 7(오른쪽)
///

우리 앱에서 레벨을 어떻게 정하는지 보면 기준을 잡기 쉽습니다. 앱을 처음 열 때는 레벨 7로 시작합니다. 서울 전체가 보이므로 저장한 장소들이 어디에 흩어져 있는지 확인하기 좋습니다. 목록에서 장소 하나를 골라 이동할 때는 레벨 4로 내려갑니다. 그 가게가 어느 골목에 있는지 보여야 하기 때문입니다. 전체를 볼 때는 큰 레벨, 한 곳을 볼 때는 작은 레벨을 씁니다.

레벨에도 값을 읽는 메서드가 있어서, `__map.getLevel()`을 부르면 현재 레벨을 알려 줍니다. 콘솔에서 `__map.setLevel(0)`이나 `__map.setLevel(99)`를 입력해 보세요. 지도는 오류를 내지 않고, 허용 범위 안에서 가장 가까운 레벨로 맞춥니다. SDK가 범위를 벗어난 값을 걸러 주기 때문입니다. 콘솔 실험은 새로고침하면 원래대로 돌아오므로 이런 값도 넣어 볼 수 있습니다.

## 10.4 지도에 버튼 달기: MapTypeControl과 ZoomControl

지금까지는 개발자인 우리가 콘솔에서 지도를 조작했습니다. 하지만 앱을 쓰는 사용자는 콘솔을 열지 않습니다. 사용자가 쓸 조작 장치를 지도 위에 붙입니다. 카카오 SDK에서는 이런 장치를 컨트롤이라고 부릅니다. 카카오 SDK는 자주 쓰는 컨트롤 두 개를 기본으로 제공합니다.

- MapTypeControl: 일반 지도와 스카이뷰(위성 사진)를 전환하는 버튼
- ZoomControl: 확대(+)·축소(−) 버튼

카카오맵 앱에서도 볼 수 있는 버튼들입니다. Claude Code에게 시켜 봅시다.

!!! tip "이렇게 물어보세요"
    > 지도 오른쪽 위에 일반지도/스카이뷰 전환 버튼을, 오른쪽에 확대·축소 버튼을 달아줘. 카카오 SDK가 기본 제공하는 컨트롤을 사용해.

Claude Code가 지도 생성 코드 바로 아래에 두 줄을 추가합니다. 우리 앱의 실제 코드에서 그대로 가져온 모습입니다.

```js
const map = new kakao.maps.Map(container, {
  center: new kakao.maps.LatLng(37.5665, 126.978),
  level: 7,
});

// 지도 타입 컨트롤 — 일반 지도 / 스카이뷰 전환 버튼
map.addControl(new kakao.maps.MapTypeControl(), kakao.maps.ControlPosition.TOPRIGHT);
// 줌 컨트롤 — 확대(+) / 축소(-) 버튼
map.addControl(new kakao.maps.ZoomControl(), kakao.maps.ControlPosition.RIGHT);
```

두 줄이 같은 구조라는 점부터 보세요. `map.addControl(무엇을, 어디에)` 형태로, `addControl` 메서드에 두 가지를 전달합니다.

무엇을: `new kakao.maps.MapTypeControl()`은 지도 타입 전환 버튼을, `new kakao.maps.ZoomControl()`은 확대·축소 버튼을 만듭니다. 9장에서 `new kakao.maps.Map(...)`으로 지도를 만들었던 것과 같은 `new` 문법입니다. 카카오 SDK의 구성 요소는 이렇게 `new kakao.maps.이름()`으로 만듭니다.

어디에: `kakao.maps.ControlPosition.TOPRIGHT`는 오른쪽 위, `RIGHT`는 오른쪽 중앙을 뜻합니다. SDK가 정해 둔 위치 이름 중에서 골라 쓰는 방식이라, `TOPLEFT`, `BOTTOMRIGHT`처럼 이름만 바꾸면 위치를 옮길 수 있습니다.

파일이 저장되면 Vite가 자동으로 새로고침해 주므로 브라우저를 그대로 보고 있으면 됩니다.

줌 컨트롤의 +/− 버튼도 눌러 보면 지도가 확대·축소됩니다. 이 버튼이 하는 일은 우리가 콘솔에서 실행한 `setLevel`과 같습니다. 버튼을 누르면 내부적으로 레벨이 1씩 오르내립니다. 화면의 버튼은 대개 이렇게 메서드 호출을 대신 실행해 주는 역할을 합니다.

!!! tip "팁"
    컨트롤을 단 뒤에도 마우스 휠 확대·축소와 드래그 이동은 그대로 동작합니다. 컨트롤은 조작 수단을 하나 더 추가하는 것이고, 원래 방식은 그대로 남습니다. 이런 기본 조작을 막는 메서드도 있습니다. `__map.setZoomable(false)`를 콘솔에 입력하면 휠 확대가 잠기고, `true`를 넣으면 다시 풀립니다. 지도를 배경으로만 쓰는 페이지에서 쓰는 기능입니다.

## 10.5 지도의 이벤트 받기: click과 dragend

지금까지는 우리가 지도에 지시를 내렸습니다. 이번에는 반대로, 지도가 보내는 신호를 받아 봅시다.

사용자가 지도를 클릭하면 지도는 클릭이 일어났다는 사실과 그 위치를 담은 신호를 발생시킵니다. 드래그를 끝내면 이동이 끝났다는 신호를 발생시킵니다. 이런 신호를 이벤트[^2]라고 부릅니다. 신호가 발생해도 그것을 받는 코드가 없으면 아무 일도 일어나지 않습니다. 그래서 신호를 받을 함수를 미리 등록해 두는데, 이 함수를 리스너(listener)라고 합니다. click 신호가 오면 이 함수를 실행하라고 예약해 두는 것입니다.

16장에서 만들 "지도 클릭으로 장소 추가" 기능의 기초가 되는 코드를 직접 만들어 봅시다.

!!! tip "이렇게 물어보세요"
    > 지도를 클릭하면 클릭한 지점의 위도·경도를 콘솔에 출력해줘. 나중에 이 좌표로 장소를 추가할 거라 좌표를 정확히 얻는 게 목적이야.

Claude Code가 `main.js`에 다음 코드를 추가합니다.

```js
// 지도 클릭 → 클릭한 지점의 좌표를 콘솔에 출력
kakao.maps.event.addListener(map, 'click', (e) => {
  const lat = e.latLng.getLat();
  const lng = e.latLng.getLng();
  console.log('클릭한 곳:', lat, lng);
});
```

새로 들어온 코드를 한 줄씩 읽어 봅시다.

- `kakao.maps.event.addListener(map, 'click', 함수)` — 이벤트를 등록하는 함수입니다. 세 가지를 전달합니다. 어떤 대상을 지켜볼지(`map`), 어떤 신호를 기다릴지(`'click'`), 신호가 오면 무엇을 실행할지(세 번째 자리의 함수)입니다.
- `(e) => { ... }` — 신호가 왔을 때 실행될 함수입니다. 화살표(`=>`)를 쓰는 자바스크립트의 함수 표기법입니다. 매개변수 `e`는 SDK가 신호와 함께 전달하는 이벤트 정보이고, 클릭이 일어났다는 사실뿐 아니라 어디를 클릭했는지도 여기에 담겨 옵니다.
- `e.latLng` — 이벤트 정보 중 클릭 지점의 좌표 객체입니다. 9장에서 다룬 `LatLng`과 같은 종류라서, `getLat()`으로 위도를, `getLng()`으로 경도를 얻을 수 있습니다.
- `console.log(...)` — 괄호 안의 내용을 개발자도구 콘솔에 출력합니다. 화면에는 아무것도 안 보이지만 콘솔에는 찍힙니다. 개발 중에 값을 확인하는 가장 기본적인 도구입니다.

저장하고 브라우저로 가서, 콘솔을 열어 둔 채 지도 아무 곳이나 클릭해 보세요.

```
클릭한 곳: 37.56682420267543 126.97865225189799
```

클릭할 때마다 콘솔에 좌표가 한 줄씩 출력됩니다. 시청 앞, 한강, 스카이뷰로 바꾼 뒤 남산을 차례로 클릭해 보세요. 지도 위의 모든 지점이 숫자 두 개로 표현된다는 것을 확인할 수 있습니다. 10.2절에서 쓴 해운대 좌표도 이렇게 얻습니다. 지도를 축소해 해운대를 찾아 클릭하면 좌표가 콘솔에 나타납니다.

이벤트를 하나 더 들어 봅시다. 이번엔 `dragend`를 씁니다. 사용자가 지도를 끌다가 손을 뗀 순간에 오는 신호를 받습니다.

```js
// 드래그가 끝나면 → 새 중심 좌표를 콘솔에 출력
kakao.maps.event.addListener(map, 'dragend', () => {
  const c = map.getCenter();
  console.log('지도 중심 이동:', c.getLat(), c.getLng());
});
```

구조는 앞의 코드와 같고, 달라진 것은 신호 이름 `'dragend'`와 실행 내용뿐입니다. 한 가지 차이는 이번 함수에 `(e)`가 없다는 점입니다. 드래그 종료 이벤트는 클릭과 달리 특정 지점 정보를 전달하지 않으므로, 대신 `map.getCenter()`를 호출해 새 중심 좌표를 직접 읽었습니다. 메서드와 이벤트를 한 코드 안에서 함께 쓰는 예입니다. 지도를 끌어 보면 손을 뗄 때마다 새 중심 좌표가 콘솔에 출력됩니다.

이벤트 이름은 이 밖에도 `zoom_changed`(레벨 변경), `rightclick`(우클릭) 등 여러 가지가 있습니다. 전부 외울 필요는 없고, 지도에 어떤 일이 생기면 신호가 발생하고 `addListener`로 그 신호를 받을 수 있다는 구조만 알면 나머지는 필요할 때 Claude Code에게 물어보면 됩니다.

!!! tip "팁"
    콘솔에 좌표를 출력하는 이 방식은 실제 개발에서 자주 쓰는 방법입니다. 새 기능을 만들 때 화면부터 만들지 않고, 먼저 `console.log`로 값이 제대로 들어오는지 확인합니다. 16장에서는 이번에 만든 클릭 리스너의 `console.log` 자리를 장소 추가 입력창을 여는 코드로 바꿉니다. 구조는 이번 장에서 이미 만들어 두었습니다.

## 10.6 마무리

이번 장에서는 지도를 보기만 하던 상태에서 코드로 조작하는 단계로 넘어왔습니다. 콘솔에서 메서드를 직접 실행해 보고, 같은 내용을 코드에 옮겼습니다.

이번 장에서 한 일을 짚어 봅시다. 지도 객체의 메서드로 지도를 조작했습니다. `setCenter`는 즉시 이동, `panTo`는 애니메이션 이동, `setLevel`은 확대 단계 변경이고, `get`으로 시작하는 메서드로 현재 상태를 읽을 수 있습니다. 사용자용 조작 장치는 `addControl`로 지도 타입 버튼과 줌 버튼을 달았습니다. 반대 방향으로는 `addListener`로 지도가 보내는 신호를 받았습니다. 클릭한 지점의 좌표를 얻는 이 기능을 이 책 후반부에서 계속 씁니다.

!!! abstract "이 장의 핵심"
    - 지도 객체(`map`)는 메서드를 통해 조작합니다. `window.__map`으로 노출하면 콘솔에서 바로 실행해 볼 수 있습니다.
    - `setCenter`는 즉시 이동, `panTo`는 부드러운 이동입니다. 단, 이동 거리가 화면보다 훨씬 멀면 `panTo`도 애니메이션을 생략합니다.
    - 레벨은 1(최대 확대)부터 14(한반도 전체)까지이며, 숫자가 작을수록 확대됩니다. 전체를 볼 때는 큰 레벨, 한 곳을 볼 때는 작은 레벨을 씁니다.
    - `map.addControl(컨트롤, 위치)`로 MapTypeControl(지도/스카이뷰 전환)과 ZoomControl(+/−)을 달 수 있습니다.
    - `kakao.maps.event.addListener(map, '이벤트이름', 함수)`로 지도의 신호를 듣습니다. `click` 이벤트의 `e.latLng`에서 `getLat()`/`getLng()`로 클릭 좌표를 얻습니다.

!!! info "더 찾아보기"
    - `kakao.maps.event.removeListener` — 등록한 리스너를 떼어 내는 메서드. 리스너를 붙였다 뗄 수 있어야 하는 상황을 검색해 보세요.

    - `지오코딩(geocoding)` — "서울시청" 같은 주소·이름을 좌표로 바꾸는 기술. 15장의 장소 검색이 이 기술의 사촌입니다.

[^1]: 메서드(method) — 객체에 딸려 있는 함수. `객체.메서드()` 형태로 호출하며, 그 객체를 조작하거나 정보를 읽는 역할을 합니다.
[^2]: 이벤트(event) — 클릭, 드래그, 키 입력처럼 프로그램 안에서 "일어난 사건"을 알리는 신호. 이벤트에 함수를 등록해 두면(리스너) 사건이 일어날 때마다 그 함수가 자동으로 실행됩니다.
