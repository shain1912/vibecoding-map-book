[13] 그림 8.1 — Claude Code가 npm create vite 명령어로 프로젝트 구조를 생성하는 모습
[14] AI가 실행하는 명령어의 종류를 확인해 보겠습니다. 이번 절에서 실행할 명령어는 총 세 줄로 구성됩니다.
[15] 명령어를 직접 입력하지 않고 AI를 통해 작업하는 경우에도 관련 설명을 제시하는 이유는 다음과 같습니다. AI가 수행하는 작업 내용을 정확히 파악하고 있어야, 문제가 발생하였을 때 원인을 파악하고 대응하기 쉽기 때문입니다.
[16] 프로젝트 생성 및 설치 작업이 완료되면 Claude Code가 작업 완료 메시지를 전송할 것입니다. AI의 안내에 따라 작업이 완료되었더라도 실제로 프로젝트가 정상적으로 생성되었는지 직접 확인하는 것이 좋습니다. 파일 탐색기를 열어 방금 생성된 【15】 폴더가 존재하는지 확인해 보시기 바랍니다.
[17] 폴더가 정상적으로 생성된 것을 확인하였다면, 다음 절로 진행하기 전에 한 가지 사항을 추가로 검토하여야 합니다. 앞서 실행한 명령어 중 【16】은 해당 명령어를 실행하는 동안에만 유효한 경로 정보를 가집니다. 현재 Claude Code 세션은 최초에 【17】를 실행한 상위 폴더를 작업 대상 경로로 인식하고 있을 수 있습니다. 따라서 현재 세션을 종료하고, 【18】 폴더 내부에서 Claude Code를 다시 실행한 뒤 작업을 계속 진행하시기 바랍니다.
[18] 새 세션이 시작되면 Claude Code에게 【20】라고 질문하여 보시기 바랍니다. 응답받은 경로의 마지막 부분이 【19】와 일치한다면 작업 경로가 정상적으로 설정된 것입니다.
[19] 이 확인 절차를 생략하고 작업 경로가 상위 폴더인 상태로 작업을 진행할 경우, 8.6절에서 생성할 【21】 파일이 【22】 외부에 생성되는 문제가 발생할 수 있습니다. 이 경우 파일 내용 자체에는 문제가 없기 때문에 원인을 파악하기 어려우며, 9장에서 키 값을 불러올 때 【23】와 같은 오류가 발생하고 지도가 정상적으로 표시되지 않게 됩니다. 따라서 본문의 모든 실습은 【24】 폴더 내부에서 Claude Code를 실행한 상태로 진행하는 것을 기준으로 합니다.
[20] 【25】 폴더를 열어보시면 다음과 같은 형태의 기본 구조가 확인될 것입니다.

[25] 【30】에는 프로젝트 실행에 필요한 패키지 파일들이 저장됩니다. 해당 폴더를 열어보면 수백 개의 하위 폴더가 포함된 것을 확인할 수 있습니다. 이 폴더의 내용을 직접 수정하거나 원격 저장소에 업로드할 필요는 없습니다. 필요한 패키지 목록은 별도의 【32】 파일에 기록되어 있으므로, 【33】 명령어 한 번으로 언제든지 동일한 환경을 복원할 수 있습니다.
[26] 【34】에는 프로젝트의 기본 정보와 의존하는 패키지 목록이 기록됩니다. 해당 파일을 열어보시면 현재 프로젝트의 구성 내용을 확인할 수 있습니다.
[27] 파일의 주요 항목별 의미를 살펴보겠습니다. 【35】과 【36】에는 프로젝트의 이름과 버전 정보가 명시됩니다. 【37】 항목은 Vite 템플릿에서 기본으로 제공하는 값입니다. 버전 번호나 Vite의 버전은 프로젝트 생성 시점에 따라 달라질 수 있으므로, 본문에 기재된 내용과 약간의 차이가 있더라도 문제는 없습니다. 【38】에는 프로젝트에서 자주 사용하는 명령어를 간략하게 등록할 수 있습니다. 터미널에서 【39】라고 입력하면 npm이 해당 파일을 참조하여 【40】에 해당하는 실제 명령어를 대신 실행하게 됩니다. 개발 서버 실행은 【41】, 배포용 파일 생성은 【42】, 생성된 결과물 미리보기는 【43】 명령어로 수행하며, 세 가지 명령어를 앞으로 반복적으로 사용하게 될 것입니다. 【44】에는 개발 환경에서 필요한 패키지가 명시되는데, 현재는 Vite 7 패키지만 등록된 상태입니다. 【45】 명령어가 이 목록을 참조하여 필요한 패키지를 내려받게 됩니다.

[35] 그림 8.4 — 브라우저에서 확인한 Vite 기본 환영 페이지
[36] 개발 서버의 주요 기능을 확인해 보겠습니다. 서버를 실행한 상태에서 【53】 파일을 열어 임의의 내용을 수정하고 저장해 보시기 바랍니다. 브라우저에서 별도로 새로고침을 수행하지 않아도 화면 내용이 자동으로 변경된 것을 확인할 수 있습니다. 이것은 Vite의 즉시 반영 기능이며, HMR【52】이라고 부릅니다. 앞으로 프로젝트를 진행하면서 Claude Code가 코드를 수정하면 브라우저 화면이 자동으로 갱신되므로, 별도의 조작 없이 결과만 확인하시면 됩니다.
