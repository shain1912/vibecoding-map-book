[50] 그렇다고 도메인 제한이 있으니 키를 아무 데나 올려도 되는 것은 아닙니다.

[51] 먼저 도메인 제한이 모든 키를 보호하지는 않습니다. 도메인 제한은 JavaScript 키에만 적용됩니다. REST API 키나 어드민 키는 성격이 달라서 유출되면 실제 피해로 이어집니다. 키마다 위험한지 아닌지를 매번 따지기보다, 어떤 키든 공개하지 않는다는 기준을 한결같이 지키는 편이 낫습니다.

[52] 그리고 앞으로 다룰 키 중에는 유출되면 곧바로 요금이 청구되는 것도 있습니다. 유료 AI API 키가 그렇습니다. 첫 키부터 코드와 분리해 보관해 두면 그런 키를 다룰 때도 같은 방식으로 처리할 수 있습니다.
